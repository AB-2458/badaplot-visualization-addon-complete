1. WHAT THE PROJECT IS
================================================================================

This project is an "Interactive Plot Availability System" -- a full-stack
web application built as a PREMIUM FEATURE exclusively for the TOP-TIER
users of the real estate portal badaplot.com.

It is NOT a standalone product. It is an integrated addon that will be
unlocked for badaplot.com's highest-tier subscribers (e.g. Diamond plan
agents, premium developers). As badaplot.com grows its user base, more
and more agents and developers will gain access to this digitizing portal
to visualize their plot layouts and share live, real-time plot links with
prospective buyers.

The system has two core pillars:

  PILLAR 1 - THE DIGITIZING PORTAL:
  Allows top-tier users to:
    (a) Upload a PDF or high-resolution image of their land/plot layout
        (e.g. a site plan from a surveyor or architect).
    (b) Digitize that layout by drawing interactive polygons (SVG paths)
        over each individual plot on the image.
    (c) Assign rich metadata to each plot: plot number, area (sq.ft),
        price per sq.ft, total price, facing direction, type, and live
        status (Available / Sold / Reserved / Hold / Registered, etc.).
    (d) Publish the digitized layout as a live, interactive, color-coded
        plot map that end-users (buyers) can click, filter, and browse
        directly on badaplot.com.
    (e) Share a direct link to their project's real-time plot map with
        anyone -- the link always shows the latest live status of every
        plot (no stale data).

  PILLAR 2 - THE BOTH-SIDE LEDGER / DEALFLOW DASHBOARD:
  A dedicated multi-project portal built for the 5 KEY STAKEHOLDER
  ROLES that participate across different real estate projects
  simultaneously. These 5 characters (e.g. Developer, Agent, Buyer,
  Finder/Broker, Admin) each have their own view within a unified
  dashboard that tracks:
    - Deal pipelines across multiple projects at once
    - Commission tracking per stakeholder per project
    - Both-side financial ledger (money in vs. money out)
    - Payment schedules and receipts
    - Lead management and status tracking
    - Finder fees and document management
  This ensures that every character involved in any project can log in
  and see their complete financial and operational picture across ALL
  the projects they are part of, in one place.

3. HOW IT WAS BUILT (Technology Decisions)
================================================================================

  RENDERING APPROACH:
    The plot visualization uses a "hybrid raster-vector" technique.
    A high-resolution image (PNG, from a PDF or scan) serves as the
    static background layer. On top of it, an SVG layer is positioned
    with matching dimensions (via a configurable viewbox like
    "0 0 1600 900"). Each plot is an SVG <path> element with polygon
    coordinates stored as simple SVG path strings (e.g.
    "M50,50 L120,50 L120,100 L50,100 Z"). This means:
      - The background image can be any resolution (300-600 DPI).
      - Plot boundaries are infinitely scalable vectors.
      - Zoom and pan are pure CSS transforms on the container,
        never touching the coordinate data.
      - Each plot stores its centroid (x,y) for label positioning.

  DATA MODEL:
    Each project is a single JSON object containing:
      - project: { id, name, description, location }
      - svgViewbox: "0 0 [width] [height]"
      - plots: [ { id, number, status, type, areaSqft, pricePerSqft,
                    totalPrice, facing, svgPath, centroidX, centroidY } ]

  ARCHITECTURE:
    - Frontend and backend are decoupled (CORS-enabled REST API).
    - The dashboard connects to Supabase for persistent PostgreSQL
      storage and user authentication.
    - The visualization widget is fully data-driven: swap the JSON
      config and background image, and a new project renders with
      zero code changes.

  DEPLOYMENT INFRASTRUCTURE:
    - Frontend: Vercel (serverless edge deployment).
    - Backend: Node.js server (can run on any cloud provider).
    - Database: Supabase (managed PostgreSQL).


4. HOW IT WORKS AS A PREMIUM ADDON FOR BADAPLOT.COM
================================================================================

  WHO GETS ACCESS:
    This feature is EXCLUSIVELY for badaplot.com's top-tier subscribers.
    It is NOT available to free-tier or basic-tier users. As badaplot.com
    grows and acquires more premium subscribers, the volume of digitized
    projects on the platform will scale proportionally -- each new
    top-tier user will digitize their own layouts and publish shareable
    real-time plot links.

  INTEGRATION MODEL:
    When a buyer on badaplot.com clicks on a project listing (for example,
    "Shri Vitthal Park" in Pune), instead of seeing just photos and text,
    they see a live, interactive plot map showing exactly which plots are
    Available (green), Sold (red), Reserved (orange), etc. This is the
    competitive differentiator -- no other Indian real estate portal
    provides this level of real-time, interactive plot visualization.

  HOW IT PLUGS IN:
    1. Each project on badaplot.com has a unique project ID.
    2. The widget fetches its JSON config from the API using that ID.
    3. The widget renders the interactive plot map inside the project
       listing page.
    4. No code changes are required per project -- only new data and
       a new background image.

  SHAREABLE REAL-TIME LINKS:
    Top-tier users can share a direct URL (e.g. plots.badaplot.com/xyz)
    to anyone. This link always shows the LIVE status of every plot.
    When a plot is marked Sold, the link updates instantly for everyone
    viewing it. This eliminates stale brochures, outdated PDFs, and
    manual WhatsApp updates that agents currently rely on.

  EMBEDDABLE APPROACHES:
    Option A: Direct React component import (badaplot.com is React).
      <PlotLayout
        plots={projectData.plots}
        svgViewbox={projectData.svgViewbox}
        onPlotClick={handlePlotClick}
      />

    Option B: iframe embed for any website.
      <iframe src="https://plots.badaplot.com/?project=xyz" />

    Option C: Web Component (future).
      <badaplot-viewer project-id="xyz"></badaplot-viewer>

  THE 5-STAKEHOLDER LEDGER:
    Real estate deals in India involve multiple parties across multiple
    projects. The Dealflow Dashboard provides a unified portal where
    each of the 5 key stakeholder roles can log in and see their
    complete picture across ALL projects they are part of:

      Stakeholder 1: Developer / Landowner
        - Sees all their projects, plot availability, total revenue.

      Stakeholder 2: Agent / Broker
        - Sees assigned projects, commissions earned, leads managed.

      Stakeholder 3: Buyer / Investor
        - Sees their purchases, payment schedules, documents.

      Stakeholder 4: Finder / Referrer
        - Sees finder fees, referral chains, payouts.

      Stakeholder 5: Admin / Platform Operator (Badaplot)
        - Sees everything: all projects, all stakeholders, all money
          flow, both-side ledger.

    This is critical because each of these 5 characters is typically
    involved in MULTIPLE projects at the same time. Without a unified
    ledger, they would need to track spreadsheets per project. This
    dashboard eliminates that entirely.

  ADMIN WORKFLOW:
    1. Top-tier agent logs into the Dealflow Dashboard.
    2. Uploads a PDF/image of the site layout.
    3. Uses the Plot Digitizer to draw polygons over each plot.
    4. Assigns metadata (number, area, price, status) to each plot.
    5. Saves. The public plot map is now live on badaplot.com.
    6. Shares the real-time link with buyers via WhatsApp/email.
    7. As plots are sold, the agent updates status in the dashboard.
    8. The public map and shared link update in real-time.
    9. All 5 stakeholders see the financial impact in their ledger.
